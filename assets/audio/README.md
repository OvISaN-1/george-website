# Real recordings for the games (optional)

The walk-out tune, goal song and crowd chants are made up by the game itself (see `quiz-zone/gz-music.js`),
so nothing needs to be here. If you would like real recordings instead, put audio files in this folder
with these exact names and the games will play them in place of the made-up ones:

| File                     | Plays when                                          |
|--------------------------|-----------------------------------------------------|
| `walkout.mp3`            | the teams walk out at the start of a match / round  |
| `goal.mp3`               | Forest score                                        |
| `chant.mp3`              | now and then from the stands, and after a save      |
| `win.mp3`                | full time, when Forest have won                     |

`.mp3` or `.ogg` files work (the game tries `.mp3` first).
Keep each file short (under about 15 seconds) and only use recordings you made yourself or that are
free to use. Songs and recordings by other people are usually copyrighted, so please don't upload those.
