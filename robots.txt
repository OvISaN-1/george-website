# This site currently sets "noindex, nofollow" on every page (see each page's
# <meta name="robots"> tag) because it's a personal, privacy-first page for a
# child and isn't meant to show up in search results or be crawled for links.
# robots.txt intentionally does NOT block crawling here — search engines need
# to actually fetch a page to see its noindex tag and honour it. Blocking
# crawling in robots.txt would be redundant with the meta tag and would also
# stop things like link-preview bots (e.g. WhatsApp/iMessage) from reading the
# Open Graph tags when a link is shared privately.
#
# No sitemap.xml is included for the same reason: submitting a sitemap is a
# request to be indexed, which conflicts with the noindex tags above. If you
# ever decide you *want* the site to appear in search results, remove
# "noindex, nofollow" from every page's <meta name="robots"> tag, then add a
# sitemap.xml and a "Sitemap:" line here.
